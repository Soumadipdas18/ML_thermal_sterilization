# Machine Learning for Thermal Sterilization

This repository contains the code, dataset, and final report for a machine-learning study on thermal sterilization.

The objective is to predict two process outputs:

- **F-value**
- **Quality retention**

using the following operating conditions as inputs:

- Come-up time
- Heating time
- Cooling time
- Heating retort temperature

The project compares three regression approaches:

- Linear Regression
- Random Forest Regression
- Feed-forward Neural Network

## Files

- `Soumadip_Das_ML_Project.ipynb` - data preprocessing, model development, hyperparameter tuning, and model evaluation
- `data_ml.csv` - dataset used for training and testing
- `Project Final.pdf` - final project report

## Running the notebook

Open `Soumadip_Das_ML_Project.ipynb` in Jupyter Notebook or Google Colab and run the cells in order.
